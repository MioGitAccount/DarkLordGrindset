# Castle factions - design (built 2026-10-31)

The Dark Lord unites 4 factions. The castle build window has the Tower in the middle and one layer per
faction: Chaos and Stronghold on the left, Dark Humans and Undead on the right.
Decisions below were picked by the user; items marked *(default)* are my proposals, open to change.

## Tower

Tower I / II / III as today (max level 3). The tower level caps the faction base level:
faction base L2 needs Tower II, base L3 needs Tower III.

## Faction bases

| Faction | Base building | Recruits |
|---|---|---|
| Chaos | Imp Den | Imp |
| Stronghold (orcs, goblins) | Orc Pit | Orc |
| Dark Humans | Witch's Hut | Witch |
| Undead | Crypt *(default name)* | Skeleton (new unit, placeholder art) |

- All 4 start built at level 1. A map file can override which bases start built.
- Max level 3. **Base level = number of building slots** in that layer (L1 = 1, L2 = 2, L3 = 3).
- Each level also raises that faction's **unit cap**: imp/orc/skeleton 4 / +2 / +2, witch 2 / +1 / +1 *(default)*.
- Some slot buildings need a minimum base level (see below).
- Upgrade cost *(default)*: L2 around today's level-2 building costs, L3 around today's level-3 costs.

## Slot rules

- A faction building can only go in its own faction's layer. A neutral building fits a slot in any layer.
- Every building is unique: at most one of each in the whole castle.
- A slot building can be demolished to free the slot *(default: 50% refund)*.

## Slot buildings

| Building | Layer | Needs | Effect |
|---|---|---|---|
| Imp Academy | Chaos | base L2 *(default)* | imps recruited +2 levels, +1 imp cap |
| Torture Chamber | Chaos | - | own castle quest pool: interrogation quests (new content) |
| Infernal Library | Chaos | base L3 | imps recruited +2 more levels, +2 imp cap |
| Arena | Stronghold | - | own castle quest pool: the existing Arena quests |
| Orc War Camp | Stronghold | base L2 *(default)* | orcs recruited +2 levels, +1 orc cap |
| Warlord's Hall | Stronghold | base L3 | orcs recruited +2 more levels, +2 orc cap |
| Prison | Dark Humans | - | own castle quest pool: prisoner quests (the Escaped Prisoner line moves here) |
| Healing Hut | Dark Humans | - | units standing on the castle field heal over time (like a permanent Herbalist) |
| Graveyard | Undead | - | skeletons (undead) recruited +2 levels |
| Bank | neutral | - | +0.5 gold/tick *(default amount)* |
| Dark Throne | neutral | Tower III | all units recruited +1 level, +2 agent cap |
| Item Shop | neutral | - | later |

Quest buildings spawn their quests on the castle field on their own timer *(default: every 3-4 min,
one open at a time per building)*, separate from the random map quests.

## Data

- `castle_buildings.tres` is generated by `tools/castle/make_castle_buildings.py` (edit the tables there
  and re-run, or edit the .tres in Godot).
- `BuildingDefinition`: `Faction`, `IsFactionBase`, `UpgradeCostLevel2/3`, `UnitCapPerLevel`, `MinBaseLevel`,
  `HealInterval`, `QuestPool` + `QuestIntervalMin/Max`. `Castle` keeps base levels and slot contents.
- Quests in any building's `QuestPool` never spawn at random (QuestManager). A building quest appears on the
  castle when it fits the Castle biome, else on an explored field near it (the Prison's escaped prisoners).
  The first one comes 30 s after building it; the next one 3-4 min after the last one ends.
- Torture Chamber quests (`torture_*`, levels 1-3) are in `tools/quests/make_quests.py`.
- Map JSON: a castle field can list `"factions": ["Chaos", ...]` to start with only those bases.
- Skeleton (`unit_templates/skeleton.tres`) uses a placeholder icon, also as its battle image; make real
  art with the creature-sprite skill.

## Build window

Like the sketch: Tower column in the middle, two faction columns on each side. Each column has the
base at the bottom with 3 level pips, and 3 slots above it: built, empty (click opens a picker
of the buildings that fit) or locked (grey, needs a higher base level).
